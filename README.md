# Todo App ✅
Приложение для управления списком дел

## 🚀 Демо
Вы можете посмотреть 👉 [Демо приложения](https://todo-kovalkl.netlify.app/) 👈

## Установка и запуск 🛠️

1. Скопируйте репозиторий:

   ```bash
   git clone https://github.com/kovalkl/mindbox_test.git
2. Перейдите в директорию проекта
   ```bash
   cd mindbox_test
3. Запустите проект
   ```bash
   npm i && npm run start
## Функциональность 📌
- Добавление новых задач
- Фильтрация списка (все, активные, выполненные)
- Подсчет оставшихся задач
- Очистка выполненных задач
## Стек технологий 🛠️
- TypeScript
- React + Hooks
- MUI (Material-UI)
- Vite
